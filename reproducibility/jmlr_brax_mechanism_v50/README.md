# Brax-Spring HalfCheetah Mechanism, Hypercube Scaling, and Lossy Projection Audit (`v50`)

This package contains the 10-seed frozen-policy evaluation (`seeds/seed_*.json` and `analysis.json`) generated by `jax_experiments/analysis/run_jmlr_brax_mechanism_v50.py` across the ten preregistered Brax-Spring HalfCheetah canonical policy seeds (`88003`–`88171`).

## Contents
- `analysis.json`: Aggregated means, paired 95% $t$-confidence intervals, win counts, switch delays, and infeasibility diagnostics.
- `seeds/seed_*.json`: Per-seed evaluation summaries across all mechanism variants.

## Key Verified Findings (`n = 10` policy seeds)
1. **Hazard & Tempering Sensitivity (`M = 4`)**:
   - With positive switch hazard $h = 0.002 > 0$, the prior floor already bounds log-odds across $\delta \in \{0.90, 0.95, 0.98, 1.00\}$ (`3275.2` at $\delta=0.98$ vs. `3279.0` at $\delta=1.00$; diff `-3.7`, 95% CI `[-22.3, 14.9]`; flat plateau `3275.2–3281.2`).
   - Removing the switch floor (`h = 0, δ = 1.0`) induces severe dwell-proportional posterior lock-in: return drops to `2742.1` (`+533.1` for default BAPR, 95% CI `[359.5, 706.8]`, `10/10` seed wins; sustained switch delay `3.5` vs. `19.0` steps).
   - Ensemble size $K=5$ vs. single-head $K=1$ is essentially flat on this high-SNR offline-calibrated setup (`3275.2` vs. `3276.9`, diff `-1.6`, `[-25.7, 22.4]`).
2. **`M = 64` Polarity Hypercube (`{-1, +1}^6`, 43 Distinct Modes Sampled Across 15 Four-Block Episodes)**:
   - Uncompensated return collapses to `-198.9` (`2883.4` single-joint flip BAPR vs. `-214.3` uncompensated).
   - $O(d)$ channel-factored filter achieves `2813.0` (`+3011.9` vs. uncompensated, `10/10` wins; `89.2%` exact 64-mode / `97.89%` per-channel accuracy) with `6` scalar updates/step instead of `64`, while trailing the coupled $O(2^d)$ joint ensemble filter (`3182.0`; diff `-369.1`, `[-578.0, -160.2]`, `0/10` wins) because marginalizing the 5-head ensemble per coordinate discards cross-channel residual correlations during multi-joint flips.
3. **`0.5x` Non-Bijective Lossy Power Attenuation**:
   - Weighted box projection $\Pi_{[-1,1]^d}^W(G_{\hat z_t}^{-1} G_r a_t^{\mathrm{ref}})$ reaches `2334.9` vs. `482.9` uncompensated (`+1852.0`, `[1639.2, 2064.8]`, `10/10` wins) and tracks `95.8%` of the lossy projected true-mode oracle (`2437.4`; unattenuated reference `3416.3`; exact saturation infeasibility energy `240.605`).
